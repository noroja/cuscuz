# Cuscuz-MED (estyflow)

App de preparação para residência médica: acervo (Drive), treino livre com banco de questões, gerador de questões com IA (Groq), flashcards SRS e simulados.

## Rodar

```bash
npm install
cp .env.example .env   # preencha as chaves
npm run dev            # http://localhost:3000
```
