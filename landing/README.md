# Cuscuz-MED · landing page

Standalone landing page for the Cuscuz-MED platform. It does not replace or modify the SPA
`index.html`; it lives beside the app and can be deployed as its own static site.

Open `landing/index.html` directly, or serve the folder over HTTP (the video and fonts need a
normal origin):

```powershell
# from the repository root
python -m http.server 4173 --directory landing
# http://localhost:4173/
```

There is no build step. The CSS, JS and images are plain static files.

## Direction

- Art direction: `loud-flat-poster`, seed `977566933` (see `.taste-skill/direction-sheet.txt`).
- Palette: ink `#07090e`, deep greens `#062f2b` / `#0e121b`, paper `#eef2f1`, accent `#00d4b8`.
- Type: Outfit 400–800 only. Five sizes at every measured width: 1440 px 16 / 20 / 58 / 130 / 216;
  768 px 16 / 20 / 36 / 58 / 120; 390 px 16 / 20 / 32 / 47 / 120. The roles are the same; only the
  steps change.
- The hero is a full-bleed type marquee over a duotone anatomy plate; the page then moves
  through a live acervo search, a 9-tile product mosaic (6-column grid on tablet, snap filmstrip
  on phones), a proof board, the four study stages, the FAQ, the closing CTA with the three
  headline counts and a photographic footer.

## What is live

| Piece | Behaviour |
| --- | --- |
| Acervo search | Filters 32 real catalogue items from `content.js` as you type; the result rows link to the app. |
| Video | Muted, looping CC BY 3.0 clip in the visible “Acervo” tile; its still poster sits in the “Assista” stage. |
| Stages | Four-button accordion; the open stage shows its real sample (courses, question, planner). |
| FAQ | Native `<details>` with one item open. |
| Reveal / marquee | IntersectionObserver reveal and CSS marquee; both stop under `prefers-reduced-motion`. |
| Video motion | The tile clip is paused by JS when `prefers-reduced-motion: reduce` is set. |

## Real content

`content.js` is generated by `.taste-skill/build-content.mjs` from the real repository data:

- `acervo-manifest.json` — 32 search items, 6 courses, top institutions.
- `data/questions-bank.json` — the SEMAD 2025 question used in the “Responda” stage (answer B).
- Production counts used in the copy: **10.532 aulas**, **19.239 materiais**, **953 questões**,
  **155 instituições** (2018–2026).

The wording is sample copy written for the landing; it is not pulled from the app's legal pages.

## Inspection

Report: `.taste-skill/inspect-10/report.json` — **0 FAIL, 1 WARN** at 1440, 768 and 390 px.

The five-size scale passes at every width, the CTA’s former blank stretch is filled by the three
headline counts, and the video is counted as real footage (a visible, muted, looped clip). The one
remaining warning is deliberate:

- **`side-scroll` at 390 px.** The product mosaic becomes a snap filmstrip at ≤720 px. At 768 px it
  is a normal 6-column grid; on phones the nine UI fragments cannot be read in a 2-column grid
  (the fragments are wider than a 172 px cell). The filmstrip keeps a 21 px peek of the next tile
  at 390 px, `88vw` tiles, and `scroll-snap-align: start`, so the row reads as swipeable rather
  than clipped. This is the mobile adaptation chosen for the mosaic; the inspector’s generic
  side-scroll rule is the trade-off.

Everything else passes: no decorative numbering, no eyebrow labels, no outlined cards, no
hairlines, no hidden video, no blank stretch, no overflow, and no contrast, heading or type-scale
failures.

## Deployment

The folder is self-contained and uses relative asset paths. Copy it to any static host, or to a
separate Vercel project. If it is served from the main app, put it at a path such as
`/landing/` and leave the SPA `index.html` alone. The CTA points at
`https://cuscuz-nu.vercel.app/`.

## Known limits

- The hero marquee intentionally runs wider than the viewport, so the word is clipped on some
  frames. The fixed wordmark in the nav keeps the brand readable.
- `og:image` uses the portrait anatomy plate; a 1200×630 social crop would be better before a
  campaign.
- The page depends on Google Fonts for Outfit. There is no local font fallback beyond the
  system sans.
- The clip is 667 KB and the three page images plus the poster total ~1.2 MB; that is acceptable
  for a landing page but not for a data-sensitive mobile campaign.
- The 390 px product filmstrip intentionally scrolls; it is the one accepted inspection warning.
- The page is not wired into the app's Vercel build. That is intentional: the app's boot
  routes and static middleware must not be disturbed.
